GITHUB UPLOAD GUIDE

1. Extract the ZIP.
2. Open your GitHub repository and select branch main.
3. Delete old website files that are being replaced.
4. Choose Add file → Upload files.
5. Upload every extracted file/folder directly to repository root.
6. Commit the upload.
7. Wait for Cloudflare Pages to deploy.
8. Force refresh the website with Command + Shift + R.

The repository root must contain:
index.html
assets/
css/
js/
functions/
_headers
_routes.json
package.json

Do not place everything inside another FloridaStateRoleplay-main folder.
