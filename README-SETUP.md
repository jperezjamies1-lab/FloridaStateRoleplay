## New website features

### FSRP cinematic intro
- Real intro stage followed by a separate loader stage.
- Animated Florida sunset and two palm trees.
- Left palm falls right; right palm falls left.
- Supports a direct PNG/JPG/WEBP URL or MP4/WEBM URL.
- Intro media can be changed in **Manager → Intro, Ticker & Takeover**.
- Browser autoplay rules require video to begin muted. Visitors may still hear interface sounds after interacting.

### Moving roleplay ticker
- Continuously displays application and website updates.
- Default messages include Staff, OCSO, FHP, and FFW application updates.
- Managed from **Manager → Intro, Ticker & Takeover**.

### Three-second announcement takeover
- A large announcement appears in the middle of the screen.
- It closes automatically after three seconds or when the visitor clicks X.
- The announcement ID is saved in the visitor's local storage, so that exact announcement does not reappear after reload.
- Change the Announcement ID to publish a new takeover.

### Staff Spotlight
- Featured staff avatar or initials, rank, team, reason, achievement tags, and recognition board.
- Located inside the Staff page instead of below the footer.

### Easter eggs
- Click an FSRP logo twice: opens **LWKTIMMY Role · 1 of 1**.
- Click an FSRP logo four times: starts a one-minute party with lights, confetti, and an original Web Audio synth track.
- The music is generated by the website and does not use a copyrighted commercial song.

### ER:LC Roleplay CAD
Authorized agencies:
- FBI
- FHP
- FFW
- Staff Team

Included CAD tools:
- Secure department code login
- Live dispatch feed
- Active unit board and statuses
- 911 roleplay calls
- Person / plate / username records

## Cloudflare Pages deployment

Use:
- Project type: **Pages**
- Production branch: `main`
- Framework preset: **None**
- Build command: `exit 0`
- Build output directory: `.`
- Root directory: leave blank

## Required Cloudflare KV bindings

Create and bind:
- `SITE_SETTINGS` — website Manager data
- `CAD_STATE` — CAD dispatch, units, calls, records, and reports

Optional:
- `MEDIA_BUCKET` — R2 bucket for permanent image/video/audio uploads

## Required secrets

In Cloudflare Pages → Settings → Variables and Secrets, add encrypted secrets:

- `ADMIN_TOKEN`
- `OPERATIONS_TOKEN`
- `AUTH_SECRET`
- `CAD_TOKEN_SECRET`
- `CAD_FBI_CODE`
- `CAD_FHP_CODE`
- `CAD_FFW_CODE`
- `CAD_STAFF_CODE`

Use long, different values. Never place these values in `index.html`, GitHub, screenshots, or public JavaScript.

## Local CAD testing

Run a local web server from the project folder:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` and use local demo CAD code:

```text
FSRP-DEMO
```

The demo code only works on localhost/file preview. It is not accepted by the Cloudflare API.

## Intro media

For a direct hosted file:
- Image: PNG, JPG, WEBP, GIF
- Video: MP4 or WEBM

Paste the direct file URL into Manager → Intro media URL. Large permanent uploads should use the optional R2 Asset Library.

## External ER:LC API note

The website includes a secure, working FSRP CAD API backed by Cloudflare KV. It does not claim to connect to an undocumented ER:LC game API. To sync real game players, vehicles, or server status automatically, add the official provider's API documentation, endpoint, and server-side credential later. Never put that credential in browser JavaScript.

This package includes a CSS correction ensuring the maintenance overlay stays hidden when `maintenance.enabled` is false. The overlay is only shown when enabled through Website Manager.
