Streamer Live Dashboard

Add official creators. YouTube uses a channel ID, Twitch uses a username, and TikTok currently uses the Manager live switch because TikTok does not provide a general public live-status API. Live titles must match one of your FSRP keywords.

CAD public settings

Access codes are not entered here. Set them as Cloudflare secrets named CAD_FBI_CODE, CAD_FHP_CODE, CAD_OCSO_CODE, CAD_FFW_CODE, and CAD_STAFF_CODE. Add ERLC_SERVER_KEY to connect live ER:LC players, callsigns, locations, queue, emergency calls, and vehicles. CAD_TOKEN_SECRET is optional because the CAD can reuse the Manager signing secret.

Staff Operations configuration

Staff access codes and Discord webhook URLs stay in Cloudflare encrypted secrets. The public Manager never displays or stores those values.

Required secret names

STAFF_PANEL_CODE, STAFF_SUPERVISOR_CODE, STAFF_HR_CODE, and STAFF_SESSION_SECRET. Optional unique accounts use STAFF_ACCOUNTS_JSON.

Optional Discord routes

DISCORD_STAFF_WEBHOOK is the fallback. Separate routes can use DISCORD_MODERATION_WEBHOOK, DISCORD_STAFF_INFRACTION_WEBHOOK, DISCORD_INVESTIGATION_WEBHOOK, DISCORD_LOA_WEBHOOK, DISCORD_TRAINING_WEBHOOK, DISCORD_PROMOTION_WEBHOOK, DISCORD_STAFF_REQUEST_WEBHOOK, and DISCORD_SHIFT_WEBHOOK.

Backup, restore, and publishing

Export the complete editable website state before major changes. Import restores a selected JSON backup into preview, then you can publish it.
