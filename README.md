# Florida State Roleplay Operations Platform — 4.2.0

This package preserves the working FSRP website foundation and connects the public community hub, CAD/MDT, Staff Operations, Command Suite, Watchdog, applications, appeals, verification, analytics, Discord tools, ER:LC synchronization, and live radio.

## Major systems

- Public FSRP community website and Manager
- Cinematic intro, live ticker, announcement takeover, Staff Spotlight, and streamer dashboard
- CAD/MDT with calls, units, records, citations, warrants, BOLOs, evidence, radio, camera tools, themes, and live ER:LC coordinate map
- Near-real-time WebRTC PTT radio with Durable Object signaling, department talkgroups, channel lock, priority override, panic, TURN fallback, and optional live bodycam sharing
- Staff shifts, LOAs, moderation cases, infractions, investigations, training, promotions, requests, notes, evidence, Discord delivery, exports, and audit history
- Watchdog player and moderator oversight using ER:LC evidence signals and review-first protections
- Form builder, applications, private-server join requests, ban appeals, verification, giveaways, reaction-board highlights, department hierarchy, automation, and analytics
- Optional Roblox OAuth, Discord slash-command bot, scheduled automation Worker, always-on Watchdog Worker, PWA installation, and Electron companion overlay

All FSRP modules are original implementations. The package does not include or copy proprietary code, branding, paid limits, or layouts from other community-management or CAD products.
